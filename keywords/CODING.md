# コーディング

## 説明

コーディングとは、ホームページを表示するための「ソースコード（コンピューターに指示する文）」を書くことです。
コーディングと似ている言葉に、「プログラミング」があります。
この二つの言葉の違いはなんでしょうか、確認していきましょう。
コーディングとプログラミングの違いは、2つの視点から考えられ、作業範囲の違い、言語の違いがあります。
作業範囲における違いとして、プログラミングは、コーディングを含めた作業全体のことで、設計、テスト、修正などの作業も含まれています。
つまり、コーディングは、プログラミングにおける作業の一部です。
言語における違いとして、コーディングではHTML、CSS。プログラミングではPython、Javaがメジャーに使用されると考えられます。
先ほど例に出た、HTMLとCSSの役割はそれぞれ、文字や画像のメインに作成、それらの装飾の作成と違います。
しかし、Web制作現場、解説サイト、本などの場面によって、これらが混同して使われている場合もあるので注意が必要です。
